# 参数曲线建模与交互

一个用于**参数曲线建模、交互编辑与相互转换**的可视化程序。使用 HTML5 Canvas + 原生 JavaScript 实现，单文件、零依赖，双击即可在浏览器中运行。

覆盖五种曲线：

- 线性插值曲线
- Hermite 曲线
- Catmull-Rom 曲线
- 混合抛物线（Overhauser）
- Bézier 曲线

并支持各曲线与 Bézier 形式之间的**转换可视化**。

---

## 运行方式

1. 双击打开 `参数曲线建模与交互.html`（默认浏览器即可）；
2. 无需安装任何依赖、无需联网。

> 需要 Unity 版本可另行参考本项目算法移植（见文末「关于 Unity」）。

## 功能特性

### 1. 控制点交互
- **单击空白处**：添加控制点
- **拖动控制点**：移动位置（自动更新相邻点的自动切线）
- **右键单击 / Del 键**：删除控制点
- **Del 键**：删除当前选中的点；**Esc**：取消选中
- **Hermite 模式**下每个控制点带有一个**切线手柄**，拖动绿色圆点调整切向量

### 2. 曲线构建
| 曲线 | 说明 | 是否插值控制点 |
|---|---|---|
| 线性插值 | 相邻两点直线段连接 | 是 |
| Hermite | 端点 + 切向量定义（基函数矩阵） | 是 |
| Catmull-Rom | 张力 τ 可调的三次样条 | 是 |
| 混合抛物线 | 两条抛物线的线性混合 | 是 |
| Bézier | De Casteljau 递推，任意阶 | 仅首末点 |

### 3. 曲线转换
勾选「转换为 Bézier 控制点」后，程序会用橙色方块实时绘制每种曲线的**等价 Bézier 控制多边形**：

- **Hermite → Bézier**：`B₀=P₀, B₁=P₀+T₀/3, B₂=P₁−T₁/3, B₃=P₁`
- **Catmull-Rom → Bézier**：`B₀=P₁, B₁=P₁+τ(P₂−P₀)/3, B₂=P₂−τ(P₃−P₁)/3, B₃=P₂`
- **混合抛物线 → Bézier**：即 τ=0.5 时的 Catmull-Rom 转换结果
- **线性插值 → Bézier（1 次）**：`B₀=P₀, B₁=P₁`

侧边栏会随当前曲线动态显示其公式、基函数矩阵与转换公式。

### 4. 参数动画
- 一个红色**参数点**沿曲线运动，实时显示当前参数 `t` 值
- 支持播放 / 暂停、拖拽 `t` 滑杆手动定位、调节播放速度

### 5. 其它
- 预设形状（S 形、波浪、弧形、闭环）
- 采样精度调节、Catmull-Rom 张力调节
- 控制多边形 / 切线手柄 / 被混合抛物线 等显示开关

## 数学要点

### Hermite 曲线
```
P(t) = H₀₀P₀ + H₁₀T₀ + H₀₁P₁ + H₁₁T₁
H₀₀ =  2t³ − 3t² + 1
H₁₀ =   t³ − 2t² + t
H₀₁ = −2t³ + 3t²
H₁₁ =   t³ −   t²
```

### Catmull-Rom（张力 τ）
```
P(t) = C₀P₀ + C₁P₁ + C₂P₂ + C₃P₃
C₀ = −τt³ + 2τt² − τt
C₁ = (2−τ)t³ + (τ−3)t² + 1
C₂ = (τ−2)t³ + (3−2τ)t² + τt
C₃ = τt³ − τt²
```

### 混合抛物线（Overhauser）
过 P₀P₁P₂ 的抛物线 `f` 与过 P₁P₂P₃ 的抛物线 `g` 线性混合：

```
C(t) = (1−t)·f + t·g
```

### Bézier
De Casteljau 递推：

```
P_i^(r) = (1−t)·P_i^(r−1) + t·P_{i+1}^(r−1)
```

---

## 重要结论

**混合抛物线（Overhauser）与 τ=0.5 的 Catmull-Rom 样条在数学上完全等价**：

两者均为过 P₁、P₂ 的三次曲线，且端点切向量相同（`P′(P₁)=(P₂−P₀)/2`，`P′(P₂)=(P₃−P₁)/2`），因此曲线形状一致。

本项目对二者采用了不同实现（前者用抛物线混合、后者用张力参数），并在界面中显式标注了这层等价关系。

## 文件结构

```
.
└── 参数曲线建模与交互.html   # 完整程序（HTML + CSS + JS 单文件）
```

代码内部结构（HTML 文件内的 `<script>`）：

- `evalSegment` / `evalCurveAt`：分段与全局参数求值
- `hermite` / `catmullRom` / `overhauser` / `deCasteljau`：五种曲线算法
- `bezierControlSegments`：各曲线 → Bézier 控制点的转换
- `recomputeAutoTangents`：自动切线（Catmull-Rom 规则 `(P_{i+1}−P_{i−1})/2`）
- `draw*`：渲染相关函数
- `hitTestPoint` / `hitTestTangent` 及鼠标事件：交互拾取

## 关于 Unity

本项目的算法与交互逻辑可平移到 Unity：

- 用 `LineRenderer` 绘制曲线与切线，用 `OnDrawGizmos` 绘制控制点/切线手柄；
- 用 `Camera.ScreenToWorldPoint` + 鼠标射线拾取控制点；
- 核心求值函数（Hermite / Catmull-Rom / Overhauser / Bézier）可直接改写为 `Vector3` 版本。

如有需要，可基于此 README 的公式直接实现 Unity C# 脚本。
